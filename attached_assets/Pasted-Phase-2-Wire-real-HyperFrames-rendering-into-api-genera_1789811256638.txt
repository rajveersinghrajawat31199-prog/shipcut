## Change 3 — Add a render function (new file)

Create lib/hyperframes-render.ts. Export an async function that:
- Takes: html string, request id
- Writes /tmp/renders/<id>/index.html with the html
- Writes /tmp/renders/<id>/meta.json: { "id": "main", "name": "shipcut-<id>" }
- Spawns: npx hyperframes render (cwd = /tmp/renders/<id>)
- Parses the child process stdout for progress lines that look like:
    "Capturing frame N/TOTAL (X workers)"
  For each match, computes pct = (N/TOTAL)*100 and yields
  { stage: `Capturing frame ${N} of ${TOTAL}`, pct }
- Also yields events for the phases hyperframes emits: setup, encoding,
  assembling — surface each as its own stage line
- On successful exit:
    - Locates the produced MP4 (check /tmp/renders/<id>/ for *.mp4)
    - Copies it to public/renders/<id>.mp4 (create the dir if missing)
    - Returns "/renders/<id>.mp4"
- On non-zero exit or timeout after 90 seconds:
    - Kills the child
    - Throws an error

Ensure HYPERFRAMES_BROWSER_PATH and PUPPETEER_EXECUTABLE_PATH are
inherited by the child process.

## Change 4 — Wire it into /api/generate/route.ts

After the existing 5-agent streaming loop completes normally, do this
NEW work (replace the current fake render_progress phase):

  const requestId = crypto.randomUUID()

  emit: composition_start { agent: "Composition Author" }
  const html = await streamCompositionGenerator(scrapedData, agentOutputs, (token) => {
    emit: composition_token { agent: "Composition Author", token }
  })
  emit: composition_done { agent: "Composition Author", html }

  emit: render_start { agent: "Render" }
  try {
    for await (const progress of hyperframesRender(html, requestId)) {
      emit: render_progress { agent: "Render", stage: progress.stage, pct: progress.pct }
    }
    const videoUrl = "/renders/" + requestId + ".mp4"
    emit: render_done { agent: "Render" }
    emit: done { videoUrl, fresh: true }
  } catch (err) {
    // Fallback to the cached video-map result

    emit: render_done { agent: "Render" }
    emit: done { videoUrl: fallbackUrl, fresh: false }
  }
