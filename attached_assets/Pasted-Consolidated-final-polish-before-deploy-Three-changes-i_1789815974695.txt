Consolidated final polish before deploy. Three changes in one pass:

## Change 1 — Two-tier serving (architecture pivot)

Flip the video-map cached lookup ABOVE fresh generation. Do not touch
the composition generator, hyperframes-render module, or the SSE parser.

In generate.ts:

1. After the 5-agent streaming AND the composition_start / composition_token
   / composition_done events fire (keep those exactly as they are — the
   composition is still real Claude output), check the video-map for the
   requested hostname.

2. If resolveVideoUrl returns a path other than /demo.mp4 (i.e. an actual
   curated file exists in /public/videos/ for this hostname):
   - Emit render_start
   - Emit ONE render_progress { pct: 100, stage: "Serving curated Studio Tier output" }
   - Emit render_done
   - Emit done { videoUrl: <curated path>, fresh: false, curated: true }
   - SKIP the actual hyperframes render for this request.

3. If no curated file exists (resolver returned /demo.mp4), run the fresh
   render pipeline exactly as currently implemented, and emit done with
   { fresh: true, curated: false }.

4. If the fresh render fails, fall back as currently implemented, with
   { fresh: false, curated: false, fallback: true }.
